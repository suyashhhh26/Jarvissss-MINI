# 🤖 J.A.R.V.I.S — AI Assistant

A futuristic holographic-inspired AI assistant built using HTML, CSS, and JavaScript.  
Inspired by Iron Man’s J.A.R.V.I.S interface, this project includes voice recognition, AI chat integration, animated UI, live waveform visualization, weather updates, system diagnostics, and responsive mobile support.

---

## ✨ Features

- 🎤 Voice Recognition using Web Speech API
- 🧠 AI Chat Assistant powered by Groq API
- 🔊 Text-to-Speech Responses
- 🌌 Futuristic Animated UI
- 📊 Live System Diagnostics
- 🌤 Real-time Weather Information
- 📱 Fully Responsive Mobile Interface
- ⚡ Quick Command Shortcuts
- 🎵 Animated Audio Waveform
- 🔐 Secure API Key Storage using LocalStorage
- 🌐 Interactive Particle Background

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Web Speech API
- Groq AI API
- Canvas API
- Responsive Design
